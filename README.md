# Winamp Classic Visualizer

[Install with OpenVST Manager](https://github.com/alanmarcero/alan-m-OpenVSTManager/releases/latest)

A visual companion for listening, mixing, and performance. Winamp Classic Visualizer brings the moving spectrum and oscilloscope views of Winamp’s classic player into a DAW, so you can see how a sound changes while the audio continues unchanged.

![Winamp Classic Visualizer](assets/native-ui.png)

## Features

- Switch between a spectrum analyzer and an oscilloscope.
- Choose spectrum colors, bar width, peak display, and analyzer falloff.
- Choose dotted, lined, or filled oscilloscope traces.
- Set the display refresh rate and resize the window from 1× to 10×.
- Load colors from a classic Winamp skin or use the built-in palettes.
- Save settings with the DAW project and automate the display controls.

## Use it in your DAW

Install the VST3 with [OpenVST Manager](https://github.com/alanmarcero/alan-m-OpenVSTManager/releases/latest), or download the latest package from [GitHub Releases](https://github.com/alanmarcero/winamp-classic-visualizer-vst/releases/latest). It is available for VST3-compatible DAWs on macOS and Windows.
